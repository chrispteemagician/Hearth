# raw/

The inbox. Drop anything here, unsorted, in whatever form it arrives:
a voice-note transcript, a pasted article, a screenshot's worth of notes,
a half-formed idea typed at 2am. Nothing here needs to be tidy.

Your assistant reads this folder at the start of every session (per
`CLAUDE.md`) and files anything new into `wiki/` — deciding which page it
belongs to, tagging it, and then either deleting it here or moving it
into `wiki/handovers/` if it's worth keeping verbatim.

**You never need to organise this folder yourself.** That's the whole
point of having a system that reads it for you.

Delete this file once the first real drop lands here.

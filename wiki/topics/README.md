# topics/

This folder is deliberately unopinionated. In the system Hearth was
stripped from, this level was split into `people/`, `projects/`,
`concepts/`, and `tech/` — because that's what that person's life was
actually made of. Yours might split differently: maybe `work/` and
`life/`, maybe `clients/` and `ideas/`, maybe something with no obvious
English name yet.

**Don't decide this up front.** Drop your first few real things into
`raw/`, let your assistant help you file them, and let the real shape
reveal itself after a week or two of actual use. Renaming this folder
(and updating `wiki/index.md` and `CLAUDE.md`'s folder-shape diagram to
match) is a five-minute job once you know what you actually need — don't
spend an hour designing a taxonomy before you've written a single page.

Delete this file once the real folders exist.

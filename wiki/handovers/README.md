# handovers/

One page per session worth a longer record than a line in `hot.md` or
`log.md` — a real build, a decision with a "why" worth keeping, a
conversation that mattered. Not every session needs one; a quiet session
that only updated `hot.md` doesn't.

**Naming:** `YYYY-MM-DD-short-name.md`. Pick a name that describes what
happened, not the date twice.

**Once you've written a few of these**, start a `handover-index.md` in
this folder — a table, newest first, one row per handover, so there's a
scannable list instead of just a folder of filenames. Not needed until
there's enough here to actually need indexing.

Delete this file once the first real handover exists.

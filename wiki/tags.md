# Tags — keyword lookup

*Grep this file for a topic's keywords before guessing a folder. A
folder structure only helps once you know where something lives; this
helps when you don't. Every page that gets written should add its own
tags here in the same edit — not a follow-up task.*

---

Nothing tagged yet. Format, once you start:

```
## keyword-one
- [[topics/some-page]]
- [[topics/another-page]]
```

One `##` heading per keyword, one `[[link]]` per line underneath.
